Offline tablet launch instructions

1. Copy the entire folder to the tablet.
2. Open index.html in the tablet browser.
3. The app will load React and Babel from the local vendor files in the vendor/ folder.
4. Use the sidebar and the Test mode button to validate the workflow.

Notes:
- No internet connection is needed once the files are copied.
- If the browser does not allow local file access for scripts, open the folder through a simple local server instead.
